#### **README.md for Semester Project 1**
# Semester Project 1 - Science Museum Website

This project was developed as part of the **FED MAR24 program at NoroffFEU**. The website represents an **interactive science museum**, providing visitors with details on exhibitions, AI technology, and more.

## 🌟 Features
- 📌 Responsive design  
- 🎨 Interactive UI elements  
- 📷 Image galleries and exhibition previews  
- 🔗 External links to real scientific resources  
- 🛠️ Accessible and user-friendly design  

## 🖥️ Technologies Used
- **HTML5 & CSS3**  
- **Vanilla JavaScript**  
- **Git & GitHub for version control**
